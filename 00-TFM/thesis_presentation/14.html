Hybrid Planning · Layer 2

Local Trajectory Planning: ML + Classical Integration

Learned scoring fused with classical feasibility and a hard safety gate

ML Component: Trajectory Scoring Network

Inputs

BEV map, ego state, goal position, candidate trajectories

Outputs

Per-candidate safety score ∈ [0, 1]

Training

Imitation learning from expert demos; binary cross-entropy loss

Architecture

CNN over BEV + MLP head; inference < 5 ms on edge GPU

Classical Component: Lattice Planner

Candidate Generation

Kinematically-feasible trajectories over velocity and curvature grids

Collision Checking

Inflated occupancy grid — 2-cell margin around obstacles

Kinematic Constraints

Max turning radius, velocity limits, curvature continuity

Hybrid Score

S = 0.65 · MLscore + 0.35 · (classical cost)−1

Integration Flow

Lattice Generator

20 candidates · 0.2 s/step

ML Scoring Net

Score each candidate

Safety Gate

Hard collision check — reject unsafe

Best Trajectory → MPC

Highest score among safe candidates

Fallback: Stop

No safe candidate → vehicle halts

The safety gate is a hard constraint: if no collision-free candidate exists, the vehicle stops — ML uncertainty never overrides physical safety.
